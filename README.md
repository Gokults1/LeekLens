# 🔍 LeekLens

**LeekLens** is a web application designed to help identify and report potential data leaks. The project provides a user-friendly interface for checking information and presenting the results in an accessible way.

🌐 **Live Demo:** [gokul-leaklens.vercel.app](https://gokul-leaklens.vercel.app)
💻 **Source Code:** [GitHub Repository](https://github.com/Gokults1/LeekLens)

---

## 🚀 Features

* 🔎 Check information for potential data exposure
* 📊 Present results in a simple and understandable interface
* 🌐 Web-based application accessible from any modern browser
* ⚙️ Separate frontend and backend components
* 🚀 Deployed and available online

## 💻 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/Gokults1/LeekLens.git
cd LeekLens
```

### 2. Set up the backend

Navigate to the backend directory:

```bash
cd backend
```

Install the required dependencies according to the backend configuration.

### 3. Set up the frontend

Navigate to the frontend directory:

```bash
cd ../frontend
```

Install the required dependencies according to the frontend configuration.

### 4. Run the application

Start the backend and frontend using the commands specified in their respective configuration files.
